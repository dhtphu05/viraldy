# Product Scope

Viraldy is a greenfield Vertical Creative Intelligence and Iteration OS for TikTok Shop US, POD, dropshipping, and cross-border ecommerce sellers.

Current scope is backend foundation only: modular monolith structure, multi-tenant workspace model, durable jobs, object storage, API contracts, migrations, Docker, CI, and docs.

P0 direction is creative intelligence and iteration workflows. This foundation intentionally does not implement Creative DNA, scoring, AI features, frontend code, or ViralScore runtime dependencies.

ViralScore is legacy/frozen. Reuse knowledge and fixtures only, not architecture or code.
